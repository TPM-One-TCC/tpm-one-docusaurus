# TPM One

O **TPM One** é uma plataforma web para apoiar a gestão de máquinas e ordens de manutenção da área de TPM. O projeto nasceu da necessidade de centralizar informações que hoje ficam distribuídas entre planilhas, SAP e relatórios, dificultando a visualização rápida do status das máquinas e das ordens em aberto.

## Objetivos do projeto

- Centralizar dados importantes sobre máquinas, manutenção e níveis TPM.
- Facilitar a consulta do status das ordens de manutenção.
- Apoiar gestores e equipes técnicas na identificação de pendências e atrasos.
- Tornar as informações mais acessíveis para melhorar o acompanhamento e a tomada de decisão.
